# 从零开始构建推理引擎

本文介绍如何从零开始一步步构建一个初具规模的推理引擎。

截至 2025 年 10 月，已经有多个推理引擎的实现，如
[vLLM](https://github.com/vllm-project/vllm)、
[SGLang](https://github.com/sgl-project/sglang)、
[TensorRT-LLM](https://github.com/NVIDIA/TensorRT-LLM) 等。
在这些引擎快速迭代中，我们能看到有无数的功能被添加，
它们的代码量也将越来越庞大，初学者来说会较难以上手。

实际上推理引擎是一个系统工程，其核心是模型的计算过程。
在这个基础上，我们添加前端 API、请求调度、显存优化、计算并行、集合通信等，
为推理引擎添加新的功能、移植新的模型、适配新的硬件、优化推理引擎的各项性能。

因此我希望提供一个从零开始构建推理引擎的教程，
教程中我会用我自己的思路来思考需求和实现路径。
不过系统工程中其实没有什么固定的实现方式，
读者可以按照自己的思路来修改各个模块并测试自己的实现。

基于这个目的，我采用 Jupyter Notebook 来编写教程，并将内容整理如下

## 目录

### 1. [Lesson01: PyTorch 复现 Qwen3 推理过程](lesson01/01.ipynb)

推理引擎的核心还是模型的计算过程。
因此我们以 Qwen3 模型为例，使用 PyTorch 来重现模型的推理过程。
通过这一步，我们可以了解到模型是如何在不同的推理引擎中移植的，
并理解大语言模型推理详细的计算过程。
