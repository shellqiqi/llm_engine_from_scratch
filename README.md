# 从零开始构建推理引擎

本文介绍如何从零开始一步步构建一个初具规模的推理引擎。

截至 2025 年 10 月，已经有多个推理引擎的实现，如
[vLLM](https://github.com/vllm-project/vllm)、
[SGLang](https://github.com/sgl-project/sglang)、
[TensorRT-LLM](https://github.com/NVIDIA/TensorRT-LLM) 等。
由于这些推理引擎仍然在快速不断地迭代中，每个月都会有无数的功能被添加，
涉及到模型、数据、硬件、框架、调器、通信等等，
这些推理引擎的代码量也将越来越庞大，初学者来说会较难以上手。

从我的角度来看，实际上推理引擎是一个系统工程，其核心围绕着模型的计算。
在这个基础上，再在引擎上添加前端 API、请求调度、计算并行、显存优化、集合通信等功能。
因此我希望写下一个从零开始构建推理引擎的一个**可交互**的小笔记，
记录一下我对推理引擎的思考，同时也分享给读者。
不过实现一个系统并没有什么固定的套路，
读者也可以按照自己的思路来修改各个模块并测试自己的实现。

基于这个目的，我采用 Jupyter Notebook 来编写笔记，并将内容整理如下

## 目录

### 1. [Lesson01: PyTorch 复现 Qwen3 推理过程](lesson01/01.ipynb)

推理引擎的核心是模型的计算。
因此我们以 Qwen3 模型为例，使用 PyTorch 来重现模型的推理过程。
通过这一步，我们可以了解到模型是如何在不同的推理引擎中移植的，
并理解大语言模型推理的计算过程。
